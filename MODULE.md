# lifetrace

Records how this Mac is used, locally: which app, window, document or web page is in front and for how long, whether the user is active, idle or away (locked, asleep), input counts per minute (keys/clicks/scrolls, counts only), and text visible in the focused window read through Accessibility (secrets masked; password fields, password managers and banking apps are skipped). Optional readers add browser history, Claude Code/Codex prompts, shell history, git commits, media projects and calendar. No screen recording, screenshots, audio or key identities. Answers "where did my time go today", "what was I doing at 3pm", "how many interruptions this week, longest focus", "when did I see X".

Tools: lifetrace_status → lifetrace_stats / lifetrace_timeline → lifetrace_at → lifetrace_search / lifetrace_events.
